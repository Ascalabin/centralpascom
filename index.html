Plugin Local do OBS Studio (via GitHub Pages)

Plugin OBS Offline
  1. Instale pascom_obs_github.py em Ferramentas → Scripts no OBS Studio e informe a URL deste site no GitHub Pages.
  2. Com o OBS aberto neste PC, o site conecta automaticamente na ponte local (127.0.0.1:47890) e envia o GC ao vivo sem precisar de Firebase.
  3. Para salvar novas configurações padrão direto no repositório, clique em Baixar obs-config.json e substitua o arquivo na raiz do GitHub — o plugin do OBS lerá automaticamente.
